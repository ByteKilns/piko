# Core Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the thin end-to-end core loop of the Couple Budget Planner — login, monthly income/budget setup, expense CRUD, and a live dashboard — as scoped in `docs/superpowers/specs/2026-08-17-core-loop-design.md`.

**Architecture:** Next.js 15 App Router app with Drizzle ORM against Supabase Postgres. Server Actions do all data access (no separate REST API). A `getCurrentMember()` helper resolves the authenticated user's household + household_member server-side on every action, so household IDs are never trusted from the client. Pure calculation functions (budget-vs-actual, dashboard totals) are extracted into a DB-independent module and covered by Vitest unit tests; everything else is verified by running the dev server and exercising the UI.

**Tech Stack:** Next.js 15 (App Router, TypeScript), Tailwind CSS + shadcn/ui, React Hook Form + Zod, Drizzle ORM (`drizzle-orm/postgres-js`) against Supabase Postgres, Auth.js v5 (Credentials provider, bcryptjs), Vitest.

**Design decision beyond the spec:** the spec described budget/expense "owner" as `me | partner | shared`. Since either partner should see *themselves* as "Me", that label can't be stored as a fixed value — it's implemented as a nullable foreign key to `household_members` (`null` = shared), and the UI computes "Me" vs "Partner" by comparing the row's member id to the current session's member id.

```ts
export type ExpenseLike = {
  categoryId: string;
  ownerMemberId: string | null;
  amount: number;
};

export type BudgetItemLike = {
  categoryId: string;
  ownerMemberId: string | null;
  plannedAmount: number;
};

export type IncomeLike = {
  memberId: string;
  amount: number;
};

export function categorySpent(expenses: ExpenseLike[], categoryId: string): number {
  return expenses
    .filter((e) => e.categoryId === categoryId)
    .reduce((sum, e) => sum + e.amount, 0);
}

export type BudgetVsActualRow = {
  categoryId: string;
  ownerMemberId: string | null;
  planned: number;
  actual: number;
  difference: number;
};

export function budgetVsActual(
  budgetItems: BudgetItemLike[],
  expenses: ExpenseLike[],
): BudgetVsActualRow[] {
  return budgetItems.map((item) => {
    const actual = expenses
      .filter(
        (e) =>
          e.categoryId === item.categoryId && e.ownerMemberId === item.ownerMemberId,
      )
      .reduce((sum, e) => sum + e.amount, 0);
    return {
      categoryId: item.categoryId,
      ownerMemberId: item.ownerMemberId,
      planned: item.plannedAmount,
      actual,
      difference: item.plannedAmount - actual,
    };
  });
}

export type DashboardSummary = {
  combinedIncome: number;
  totalExpenses: number;
  unallocated: number;
};

export function dashboardSummary(
  incomes: IncomeLike[],
  expenses: ExpenseLike[],
): DashboardSummary {
  const combinedIncome = incomes.reduce((sum, i) => sum + i.amount, 0);
  const totalExpenses = expenses.reduce((sum, e) => sum + e.amount, 0);
  return {
    combinedIncome,
    totalExpenses,
    unallocated: combinedIncome - totalExpenses,
  };
}
```

```ts
  providers: [
    Credentials({
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" },
      },
      authorize: async (credentials) => {
        const email = credentials?.email as string | undefined;
        const password = credentials?.password as string | undefined;
        if (!email || !password) return null;

        const [user] = await db.select().from(users).where(eq(users.email, email));
        if (!user) return null;

        const valid = await bcrypt.compare(password, user.passwordHash);
        if (!valid) return null;

        return { id: user.id, email: user.email, name: user.name };
      },
    }),
  ],
  callbacks: {
    jwt: ({ token, user }) => {
      if (user) token.userId = user.id;
      return token;
    },
    session: ({ session, token }) => {
      if (session.user) session.user.id = token.userId as string;
      return session;
```
